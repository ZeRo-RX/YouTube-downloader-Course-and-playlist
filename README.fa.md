# مدیر دانلود دوره‌های یوتیوب

![Python](https://img.shields.io/badge/python-3.8%2B-blue)
![yt-dlp](https://img.shields.io/badge/yt--dlp-2025.08.18-red)
![License](https://img.shields.io/badge/license-MIT-green)

یک ابزار حرفه‌ای برای دانلود و مدیریت دوره‌های آموزشی یوتیوب با قابلیت زمان‌بندی خودکار. این برنامه برای دانلود پلی‌لیست‌های آموزشی با کنترل کیفیت، مکانیزم تلاش مجدد و پیگیری کامل دوره‌ها طراحی شده است.

## ویژگی‌ها

### دانلودر اصلی (`youtube_downloader.py`)
- **مدیریت پلی‌لیست**: افزودن، پیگیری و مدیریت چندین پلی‌لیست یوتیوب
- **کنترل کیفیت**: دانلود تا کیفیت 1080p با تنظیمات کیفیت قابل سفارشی‌سازی
- **محدودیت حجم**: تنظیم حداکثر اندازه فایل برای هر ویدیو برای مدیریت فضای ذخیره‌سازی
- **تلاش مجدد هوشمند**: تلاش مجدد خودکار با دور زدن محدودیت جغرافیایی برای دانلودهای ناموفق
- **پیگیری پیشرفت**: نوار پیشرفت لحظه‌ای با سرعت و زمان باقی‌مانده
- **پشتیبانی از ادامه دانلود**: ادامه خودکار دانلودهای interrupted
- **تحلیل چند رشته‌ای**: تحلیل سریع پلی‌لیست با استفاده از چند رشته
- **مدیریت وضعیت JSON**: ذخیره دائمی داده‌های دوره و وضعیت دانلود

### دانلودر خودکار (`auto_downloader.py`)
- **دانلودهای زمان‌بندی شده**: دانلود خودکار دوره‌های در انتظار در زمان مشخص
- **حالت غیرتعاملی**: مناسب برای دانلودهای شبانه یا برنامه‌ریزی شده
- **مدیریت خطا**: مدیریت خطای قوی با ثبت/logging دقیق

## ساختار پروژه

```
YouTube-Course-Manager/
├── youtube_downloader.py    # برنامه اصلی با منوی تعاملی
```

## نصب

### پیش‌نیازها

- پایتون 3.8 یا بالاتر
- FFmpeg (توصیه شده برای ادغام با بهترین کیفیت)

### نصب وابستگی‌ها

```bash
pip install yt-dlp colorama
```

### نصب FFmpeg (اختیاری اما توصیه شده)

**ویندوز:**
```bash
# استفاده از Chocolatey
choco install ffmpeg

# یا دانلود از https://ffmpeg.org/download.html
```

**macOS:**
```bash
brew install ffmpeg
```

**اوبونتو/دبیان:**
```bash
sudo apt update && sudo apt install ffmpeg
```

## نحوه استفاده

### حالت تعاملی

برای مدیریت تعاملی دوره اجرا کنید:

```bash
python youtube_downloader.py
```

**گزینه‌های منوی اصلی:**
1. **[N]** افزودن دوره جدید از URL پلی‌لیست یوتیوب
2. **[D]** دانلود همه دوره‌های در انتظار
3. **[U]** به‌روزرسانی همه دوره‌های ذخیره شده (تحلیل مجدد پلی‌لیست‌ها)
4. **[Q]** خروج

**عملیات‌های دوره:**
- **[1]** دانلود / ادامه
- **[2]** تغییر کیفیت / محدودیت حجم
- **[3]** تحلیل مجدد کیفیت و حجم
- **[4]** نمایش خلاصه

### حالت دانلود خودکار

دانلود خودکار را در زمان خاص برنامه‌ریزی کنید:

```bash
python auto_downloader.py
```

**پیکربندی:**
- زمان هدف: 02:10 (قابل تنظیم در اسکریپت)
- فاصله بررسی: 30 ثانیه
- به طور خودکار همه دوره‌های در انتظار را یک بار در روز دانلود می‌کند

## پیکربندی

### تنظیمات کیفیت

این دانلودر از گزینه‌های کیفیت زیر پشتیبانی می‌کند:
- **بهترین موجود**: حداکثر 1080p (توصیه شده)
- **1080p**: فول اچ دی
- **720p**: اچ دی
- **480p**: تعریف استاندارد
- **360p**: پهنای باند کم
- **سفارشی**: تنظیم حداکثر ارتفاع (تا 1080p)

### محدودیت حجم

می‌توانید حداکثر اندازه فایل برای هر ویدیو برای مدیریت فضای ذخیره‌سازی تنظیم کنید:
- مثال: `500 MB` - ویدیوهای بزرگتر از 500 مگابایت را رد کنید
- تنظیم روی `0` برای حجم نامحدود

## ویژگی‌ها به تفصیل

### مدیریت دانلود هوشمند
- به طور خودکار ویدیوهای قبلاً دانلود شده را رد می‌کند
- فایل‌های موجود را با تطبیق عنوان شناسایی می‌کند
- از فرمت‌های ویدیویی چندگانه پشتیبانی می‌کند (.mp4, .mkv, .webm, .mov, .avi)

### مکانیزم تلاش مجدد
- ویدیوهای ناموفق به طور خودکار با موارد زیر دوباره امتحان می‌شوند:
  - مناطق دور زدن محدودیت جغرافیایی (US, DE, GB, CA)
  - انتخاب‌کننده‌های فرمت
- شکست‌های دائمی در وضعیت JSON پیگیری می‌شوند

### پیگیری پیشرفت
- نوارهای پیشرفت لحظه‌ای
- نظارت بر سرعت دانلود
- تخمین زمان باقی‌مانده
- محاسبه اندازه کل

### پایداری داده
تمام داده‌های دوره در `YouTube_Courses/[نام دوره]/playlist_info.json` ذخیره می‌شود:
```json

    "channel": "نام کانال",
    "url": "https://youtube.com/playlist?list=...",

    "folder": "مسیر/به/دوره"
  },
  "settings": {
    "quality": "best",
    "max_size_mb": null,
    "max_quality": 1080
  },
  "videos": {
    "video_id": {
      "status": "success",

      "duration": 600,
      "resolution": "1080p",
      "filesize": 50000000,
      "downloaded": true

  }
}
```

## امنیت

این پروژه:
- به هیچ وجه داده‌های شخصی را جمع‌آوری یا منتقل نمی‌کند
- به کلیدهای API یا توکن‌های احراز هویت نیاز ندارد
- فقط از داده‌های عمومی یوتیوب از طریق `yt-dlp` استفاده می‌کند
- تمام داده‌ها را به صورت محلی روی دستگاه شما ذخیره می‌کند

**توجه**: فایل‌های `playlist_info.json` شامل مسیرهای فایل محلی هستند. اگر می‌خواهید ساختار دایرکتوری خود را خصوصی نگه دارید، این فایل‌ها را به ریپازیتوری‌های عمومی کامیت نکنید.

## عیب‌یابی

### مشکلات رایج

**1. "Sign in to confirm you're not a bot"**
- این یک measure ضد ربات یوتیوب است
- دانلودر به طور خودکار مناطق مختلف را امتحان می‌کند
- برای مشکلات پایدار، در نظر بگیرید از کوکی‌ها استفاده کنید:
  ```bash
  yt-dlp --cookies-from-browser chrome "VIDEO_URL"
  ```

**2. FFmpeg پیدا نشد**
- FFmpeg را طبق دستورالعمل بالا نصب کنید
- یا از `pip install yt-dlp[ffmpeg]` استفاده کنید

**3. دانلود کند**
- یوتیوب ممکن است اتصال شما را throttle کند
- سعی کنید در ساعات کم‌ترافیک دانلود کنید
- در نظر بگیرید از VPN استفاده کنید

**4. برخی ویدیوها دانلود نمی‌شوند**
- ویدیوها ممکن است محدودیت جغرافیایی داشته باشند
- ویدیوهای خصوصی یا حذف شده به عنوان ناموفق علامت‌گذاری می‌شوند
- مکانیزم تلاش مجدد چندین بار امتحان می‌کند
